# Halimeda_Timescale

R script and data associated with Isidro et al.Changes in nitrogen source are recorded by δ15N values of a common coral reef macroalga within two weeks

## Data

- **hal_enrichment.csv**  
  Isotopic turnover in *Halimeda* under nutrient enrichment  

- **hal_thallus.csv**  
  Intra-thallus variation in nitrogen integration  

- **hal_to_caltest.csv**  
  Decalcification effects on *Halimeda* δ15N values  

- **nutrient_water.csv**  
  Nutrient concentrations in water  

## Code

- **Isidro_et_al_Rscript.R**  
  R script containing all analyses and figures
